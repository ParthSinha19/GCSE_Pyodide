How it works

Your code runs inside your own browser. There is nothing to install and no account to make.

Create a notebook

  1. Click Start Coding.
  2. Choose File → New → Notebook.
  3. Pick Python and start typing.

Save your work

  1. Press Ctrl + S (or Cmd + S).
  2. Choose File → Download.
  3. Keep the .ipynb file somewhere safe.

Carry on later

  1. Open this website and click Start Coding.
  2. Click the upload arrow in the file list.
  3. Pick your .ipynb file and open it.
I see an error that says “No module named…”

That package is not available in the browser lab yet. Check the spelling first. If it is spelt correctly, ask your teacher. Other red error messages are normal Python: read the last line to find out what went wrong.

Your notebooks are kept in this browser only. Always download your work when you finish, especially on a shared school computer.

Nothing you write is sent anywhere. Your notebooks never leave your computer unless you share the file yourself.

Stuck? Ask your teacher. Python error messages are normal and useful: read the last line first.
